````md
# ✍️ Custom Code Field – How to Use It

Welcome! This guide will help you use the **Custom Code** field to add beautiful, branded sections to your website — without needing a developer.

---

## ✅ What You Can Do

- Paste in HTML blocks like:
  - Hero sections
  - Pricing tables
  - Call-to-action cards
- Use special class names like `bg-color-primary` to match your brand colors
- Combine your content with layout helpers from Tailwind CSS

---

## 🎨 Style With These Class Names

You can use the following **pre-made class names** to apply your brand colors:

| Class Name             | What It Does                                          |
| ---------------------- | ----------------------------------------------------- |
| `bg-color-primary`     | Sets the background to your brand's **primary** color |
| `text-color-primary`   | Sets the text to your **primary** color               |
| `bg-color-secondary`   | Sets the background to your **secondary** color       |
| `text-color-secondary` | Sets the text to your **secondary** color             |

These will automatically update if your brand colors change later.

---

## 💡 Example Block You Can Paste

```html
<div class="bg-color-primary text-white p-6 rounded-xl">
  <h2 class="text-color-secondary text-2xl font-bold mb-2">
    Join Our Newsletter
  </h2>
  <p>Get updates and early access to new features.</p>
</div>
```
````

---

## 💪 Pro Tips

- Use **Tailwind CSS** layout classes like `p-6`, `rounded`, `text-xl`, `grid`, `gap-4`, etc.
- You don’t need to add `style="..."` — the class names handle that for you.
- Want to preview something from another site? Paste it here, update the class names, and you're set!
